## Game Overview

**HYPER RUSH** is an exciting 3D Endless Runner game developed as a final project for 3D Visualization and Game Development course. Players control a character who runs automatically forward while navigating obstacles, collecting coins, and achieving high scores.

### Game Description

In HYPER RUSH, players experience the thrill of an endless running adventure through a procedurally generated 3D environment. The game challenges players to:

- Navigate through randomly placed obstacles
- Collect coins to increase their score
- Survive as long as possible while the game speed progressively increases
- Master the jump mechanics with a strategic cooldown system

## Key Features

### Core Gameplay

- **Automatic Forward Movement**: Character runs forward automatically with increasing speed
- **Responsive Controls**: Smooth horizontal movement and jumping mechanics
- **Obstacle Avoidance**: Dynamic barrier placement requiring quick reflexes
- **Coin Collection**: Strategic coin placement for risk-reward gameplay
- **Progressive Difficulty**: Speed increases over time and with score

### Technical Features

- **Procedural Generation**: Endless ground tiles with randomized obstacles and coins
- **Physics Integration**: Realistic jump physics and collision detection
- **Memory Optimization**: Efficient object pooling for performance
- **Smooth Animations**: Character state animations (Running, Dead)
- **UI System**: Real-time score display and jump cooldown feedback

### Game Systems

- **Player Control System**: Input handling, movement, and state management
- **Ground Generation**: Infinite tile spawning with automatic cleanup
- **Game Management**: Singleton pattern for centralized game state
- **Camera System**: Third-person follow camera for optimal gameplay view
- **Scene Management**: Menu navigation, game restart, and back navigation with proper cleanup

## Controls

### Keyboard Controls

- **A/D Keys** or **Arrow Keys**: Move left/right
- **Space Bar**: Jump (with cooldown system)

### Gameplay Mechanics

- Character automatically runs forward
- Avoid obstacles by moving horizontally or jumping
- Collect coins to increase score and speed
- Game ends when hitting an obstacle
- Use back button to return to main menu anytime
